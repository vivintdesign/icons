# Vivint icons

The 323 icons from the Vivint KICKOFF design system, each as the original SVG and as a transparent 512 × 512 PNG.

- `svg/<slug>.svg`: original artwork, unchanged. Most icons use `fill="currentColor"`, so they take the text colour where they're placed.
- `png/<slug>.png`: 512 × 512, transparent background, rendered in black.
- `icons.csv`: one row per icon: `name,slug,category,keywords,svg_url,png_url` (keywords are separated by `;`).

Everything is served on GitHub Pages at https://vivintdesign.github.io/icons/, for example
https://vivintdesign.github.io/icons/icons.csv and https://vivintdesign.github.io/icons/svg/shield-check-fill.svg.
